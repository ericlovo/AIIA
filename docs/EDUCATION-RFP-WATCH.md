# K–12 procurement watch

The cloud worker runs in the existing AIIA GitHub repository, independently of
the Mini. It screens official state-agency pages with Jev and posts one daily
review digest to the existing AIIA Slack destination. It does not create leads,
submit bids, contact agencies or alter Mini airgap settings.

## Scope and coverage

The target is all 50 U.S. states, K–12 only, RFPs and RFIs for purchasing goods
or services. Grants-only funding, higher-education-only notices and directory
navigation are excluded by separate judgments. Source onboarding is incomplete;
`config/education-rfp-sources.json` is the actual registry, not a claim of all-state
coverage. Digests explicitly report retrieved states, unavailable sources and
coverage gaps. State education agency pages do not cover every district.

Generic HTML extraction is deliberately conservative. It requires a specific
RFP/RFI link and nearby source evidence. PDFs, dynamic portals and inaccessible
pages need dedicated adapters. A Jev score is a review signal, not confirmation
of eligibility, deadline or opportunity status. Check the linked official notice
before acting. No opportunity or deadline text is generated by an LLM.

## Runtime

Workflow: `.github/workflows/education-rfp-watch.yml`, daily at 13:00 UTC
(08:00 Central daylight time; 07:00 Central standard time). GitHub scheduled runs
can be delayed. Manual dispatch is available after deployment.

The `education-alerts` GitHub environment allows only `main`. Its encrypted secrets:
`TYPESAFE_API_KEY`, `AIIA_SLACK_BOT_TOKEN`, `AIIA_SLACK_CHANNEL_ID`,
`AIIA_SLACK_TEAM_ID`. Tokens are never stored in code, artifacts or logs. Slack
identity is checked against the expected workspace and posts use only the fixed
channel. Missing channel-read scope does not trigger a request for broader access.

Jev model: `jev-1.13.0`. Four separate probabilities must reach 0.8: K–12,
RFP/RFI, goods/services procurement and evidence of being open. At most 20 provider
attempts per UTC day; requests count before dispatch. Actual token usage is
recorded; dollar cost is unknown unless independently reconciled with billing.

## Delivery and recovery

The `education-watch-state` artifact preserves judgments, the delivery ledger,
digest and run summary for 90 days. Each run restores the immediately preceding
successful run. Missing/failed history or a GitHub rerun fails closed. The worker
persists a pending delivery before posting and records Slack's receipt afterward.
An uncertain post is never automatically repeated. Reconcile the channel receipt
and ledger before manual recovery; do not delete history to force a retry.

Artifacts may include public procurement text and Slack receipt metadata, but no
credentials. Repository users with Actions artifact access can inspect them.

To stop cloud delivery, disable the Education RFP watch workflow. Keep the Studio
bot's local loop disabled: it is not the cloud scheduler. A saved Studio bot
configuration alone does not prove a cloud run succeeded. Check the Actions run
and Slack receipt. Durable external run ingestion into Studio is not yet present.

## Initial validation — October 31, 2026

A real dry run retrieved Connecticut, Delaware and Idaho; Washington returned
403 and New York failed TLS verification. The worker evaluated one Connecticut
notice with Jev and did not select it. No matching opportunity was fabricated to
populate the digest. Delaware's feed has many null solicitation types; entries
without explicit RFP/RFI evidence are withheld. Initial configured coverage is
five states, with three successfully retrieved in this observation; 45 states
still need onboarding. Availability can differ on the cloud runner.

The provider contract also passed a separate labeled synthetic connectivity
check; that synthetic item was never sent to Slack as a real notice. Unit tests
cover delivery uncertainty, previous-run recovery, duplicate identities, closed
sections, grant exclusion, blocked sources and the Delaware adapter.
